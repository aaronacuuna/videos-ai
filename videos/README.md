# Vídeos

- `registro.csv`: una fila por vídeo. Es el histórico que se analiza para saber qué funciona. Se edita a mano o con la skill.
- `AAAA-MM-DD-slug/video.md`: el expediente completo de cada vídeo (guion, prompts, publicación, checklist y resultados). Se crea copiando `_plantilla/video.md`.
- Los archivos pesados (vídeo, audio, imágenes finales) no se guardan aquí.

Para un resumen rápido: `python3 scripts/resumen.py`
